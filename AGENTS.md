PROJECT DIRECTIVE

1. Open Null Gate.
2. Choose app for which to broker root.
3. Flip a switch providing root to the selected apk.
4. Open APK (ie: colorblndr)
5. App asks if it can function with root and you select yes as NullGate is currently been switched on to broker the privilage.
6. Make the changes within the APK (ie: change themes with colorblndr).
7. Close APK (ie: colorblndr)
8. In Nullgate flip root broker switch to off.
9. Close nullGate.
