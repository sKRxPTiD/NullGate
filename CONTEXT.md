# Canonical placement

```
Null Protocol
└── PiXi
    └── NullGate
```

NullGate is not a separate peer device or product. It is PiXi's controlled,
temporary privilege layer. Its early work remains isolated from permanent
root, Magisk, and system partition changes.

The workstream is deliberately universal: the broker model is intended to
support later approved PiXi capabilities through separately verified leases.
ColorBlendr is only the initial compatibility target.
